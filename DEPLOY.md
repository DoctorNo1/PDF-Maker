# Деплой бота на Netlify

Покрокова інструкція: від порожнього акаунта до працюючого бота.
Загалом ~10 хвилин. Нічого встановлювати на комп'ютер не обов'язково —
є варіант повністю через браузер.

Що вийде в результаті: сайт на Netlify, у якому живе функція
`/telegram`. Telegram шле на неї повідомлення, вона складає PDF і
відправляє файл назад.

---

## Крок 0. Що знадобиться

- акаунт [GitHub](https://github.com) з цим репозиторієм (`DoctorNo1/PDF-Maker`);
- акаунт [Netlify](https://app.netlify.com) — можна зареєструватись через GitHub;
- бот у Telegram і його токен (Крок 1);
- **або** Node.js 18+ локально, **або** просто браузер (Крок 5 має обидва варіанти).

---

## Крок 1. Створити бота і взяти токен

1. Написати [@BotFather](https://t.me/BotFather) команду `/newbot`.
2. Ввести назву (будь-яку) і username — має закінчуватись на `bot`,
   наприклад `my_pdf_maker_bot`.
3. BotFather відповість токеном виду `8873066461:AAEaKA3eVmlhJ...`.

Токен — це пароль до бота. Не публікуй його в коді, скріншотах і чатах.
Якщо він десь засвітився: `/mybots` → бот → `API Token` → `Revoke current
token`, і далі використовуй новий.

Якщо бот уже створений — просто візьми токен через `/mybots`.

---

## Крок 2. Створити сайт на Netlify

1. Відкрити [app.netlify.com](https://app.netlify.com), увійти.
2. `Add new site` → `Import an existing project`.
3. `Deploy with GitHub` → дозволити доступ → вибрати репозиторій
   **PDF-Maker**.
4. Налаштування збірки залишити як є — вони підтягуються з `netlify.toml`:

   | Поле | Значення |
   |------|----------|
   | Branch to deploy | `main` |
   | Build command | `npm run typecheck` |
   | Publish directory | `public` |
   | Functions directory | `netlify/functions` |

5. Натиснути `Deploy`.

Перший деплой триває 1–2 хвилини. Після нього Netlify покаже адресу сайту
виду `https://random-name-123456.netlify.app` — **запиши її**, вона
знадобиться далі. Адресу можна змінити: Site configuration → Site details
→ `Change site name`.

---

## Крок 3. Додати змінні оточення

Site configuration → Environment variables → `Add a variable` →
`Add a single variable`. Додати три:

| Ключ | Значення | Обов'язково |
|------|----------|-------------|
| `BOT_TOKEN` | токен з Кроку 1 | так |
| `WEBHOOK_SECRET` | довгий випадковий рядок, який ти вигадаєш | ні, але варто |
| `MAX_PHOTOS` | `20` | ні (за замовчуванням 20) |

**Про `WEBHOOK_SECRET`.** Telegram додає його заголовком до кожного
запиту, а функція відкидає все, що прийшло без нього. Без секрету адреса
`/telegram` відкрита: хто її вгадає, зможе слати боту фальшиві апдейти.
Згенерувати можна командою `openssl rand -hex 32`, або просто набрати
30+ випадкових символів. Той самий рядок треба буде вставити в Кроці 5.

**Важливо:** змінні підхоплюються лише новою збіркою. Після додавання
відкрий `Deploys` → `Trigger deploy` → `Clear cache and deploy site`.

---

## Крок 4. Перевірити, що сайт живий

Відкрий у браузері:

```
https://<твій-сайт>.netlify.app/telegram
```

Має відповісти текстом `PDF Maker bot is alive`. Це означає, що функція
задеплоїлась і відповідає.

Якщо замість цього 404 — функція не зібралась: дивись `Deploys` →
останній деплой → лог збірки.

Сховище **Blobs** (там лежить черга фотографій) вмикати вручну зазвичай
не треба — на нових сайтах воно доступне одразу. Перевірити можна в
Site configuration → Blobs.

---

## Крок 5. Прив'язати бота до сайту (webhook)

Telegram має дізнатись, куди слати повідомлення. Один із двох варіантів.

### Варіант А — через браузер (нічого встановлювати не треба)

Встав у адресний рядок, підставивши свої значення:

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<твій-сайт>.netlify.app/telegram&secret_token=<СЕКРЕТ>&drop_pending_updates=true
```

Відповідь має бути:

```json
{"ok":true,"result":true,"description":"Webhook was set"}
```

Якщо `WEBHOOK_SECRET` не задавав — прибери частину `&secret_token=<СЕКРЕТ>`.

Меню команд (необов'язково, щоб у боті був список команд по кнопці «/»):

```
https://api.telegram.org/bot<ТОКЕН>/setMyCommands?commands=[{"command":"start","description":"Що вміє бот"},{"command":"done","description":"Скласти PDF"},{"command":"cancel","description":"Викинути накидані фото"},{"command":"mode","description":"A4 або розмір фото"},{"command":"help","description":"Довідка"}]
```

### Варіант Б — скриптом (якщо є Node.js 18+)

Робить те саме, плюс меню команд, однією командою:

```bash
git clone https://github.com/DoctorNo1/PDF-Maker
cd PDF-Maker
BOT_TOKEN='<ТОКЕН>' WEBHOOK_SECRET='<СЕКРЕТ>' \
  node scripts/set-webhook.mjs https://<твій-сайт>.netlify.app
```

Має вивести: `Webhook встановлено: https://<твій-сайт>.netlify.app/telegram`.

### Перевірка прив'язки

```
https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo
```

Очікувано: твій `url`, `pending_update_count: 0` і **відсутнє** поле
`last_error_message`.

---

## Крок 6. Спробувати

1. Відкрити свого бота в Telegram, натиснути `Start`.
2. Надіслати кілька фотографій.
3. Бот покаже «📸 Фото в черзі: N» з кнопкою — натиснути **📄 Зробити PDF**.
4. У відповідь прилетить `photos_20260919_143000.pdf`.

Якщо потрібні сторінки без білих полів (сторінка = розмір фото) —
команда `/mode`.

---

## Оновлення коду

Netlify стежить за гілкою `main`: кожен push у неї автоматично
передеплоює сайт. Нічого руками робити не треба — webhook лишається
прив'язаним, бо адреса сайту не змінюється.

Гілки й pull request'и деплояться окремими preview-адресами і на бота не
впливають.

## Якщо щось не працює

Перше, куди дивитись — логи: Netlify → `Logs` → `Functions` → `telegram`.
Там видно кожен апдейт і помилки.

| Симптом | Причина і що робити |
|---------|---------------------|
| Бот мовчить на будь-що | Перевір `getWebhookInfo`. Порожній `url` — webhook не прив'язаний (Крок 5). |
| `getWebhookInfo` показує `last_error_message: Wrong response from the webhook: 403 Forbidden` | `WEBHOOK_SECRET` на сайті і в `setWebhook` різні. Постав однакові або прибери секрет з обох місць. |
| У логах `misconfigured` / 500 | Не заданий `BOT_TOKEN`, або після його додавання не було нового деплою (Крок 3). |
| `/telegram` віддає 404 | Функція не зібралась — дивись лог останнього деплою. |
| Бот приймає фото, але на кнопку відповідає «❌ Не вдалося скласти PDF» | Формат не JPEG/PNG (наприклад HEIC чи WebP файлом) — надішли як звичайне фото, Telegram сам перетворить у JPEG. |
| Велика пачка фото не складається, у логах таймаут | Ліміт часу функції (10 с на безкоштовному плані). Зменш `MAX_PHOTOS`, роби PDF частинами. |
| Черга фото «застрягла» | `/cancel` очищає її. |
| У логах помилка від Blobs | Site configuration → Blobs, увімкнути сховище. |

---

## Як зупинити бота

- Тимчасово: `https://api.telegram.org/bot<ТОКЕН>/deleteWebhook` — Telegram
  перестане слати апдейти, сайт лишиться.
- Назовсім: видалити сайт у Netlify (Site configuration → Danger zone) і
  зробити `/deletebot` у @BotFather.
