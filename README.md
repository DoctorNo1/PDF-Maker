# PDF Maker — телеграм-бот «фото → PDF» на Netlify

Кидаєш боту фотографії — отримуєш один PDF-файл, де кожне фото окрема сторінка.
Працює як Netlify Function (webhook), без власного сервера.

## Як користуватись

1. Надсилаєш фото: альбомом або по одному.
2. Бот тримає їх у черзі й показує лічильник з кнопкою.
3. Тиснеш **📄 Зробити PDF** (або `/done`) — у відповідь прилітає
   `photos_YYYYMMDD_HHMMSS.pdf`.

Порядок сторінок = порядок, у якому надіслані фото.

| Команда           | Що робить                                               |
|-------------------|---------------------------------------------------------|
| `/start`, `/help` | Коротка довідка                                          |
| `/done`           | Скласти PDF з того, що в черзі                           |
| `/cancel`         | Викинути накидані фото                                   |
| `/mode`           | Сторінки A4 (за замовчуванням) ↔ розмір фото             |

Приймаються і звичайні фото, і зображення, надіслані файлом (без стиснення) —
другий варіант дає кращу якість. Формати: JPEG і PNG.

## Деплой на Netlify

Покрокова інструкція — у [DEPLOY.md](DEPLOY.md). Коротко:

1. Створити бота в [@BotFather](https://t.me/BotFather) і взяти токен.
2. На [app.netlify.com](https://app.netlify.com) імпортувати цей репозиторій —
   build command і publish directory підтягнуться з `netlify.toml`.
3. Додати змінні оточення `BOT_TOKEN`, `WEBHOOK_SECRET`, `MAX_PHOTOS`
   (див. `.env.example`) і передеплоїти сайт.
4. Прив'язати webhook до задеплоєного сайту:

   ```bash
   BOT_TOKEN=... WEBHOOK_SECRET=... node scripts/set-webhook.mjs https://<твій-сайт>.netlify.app
   ```

## Локальна розробка

```bash
npm install
npm test            # vitest
npm run typecheck   # tsc --noEmit

cp .env.example .env
npx netlify dev     # локальний сервер + емуляція Blobs
```

Щоб потикати бота локально, потрібен публічний URL (наприклад `netlify dev --live`
або тунель) — Telegram шле апдейти тільки на HTTPS-адресу.

## Що де лежить

| Файл                            | Призначення                                     |
|---------------------------------|-------------------------------------------------|
| `netlify/functions/telegram.mts`| Webhook: перевірка секрету, виклик логіки        |
| `src/bot.ts`                    | Обробка апдейтів: фото, команди, кнопки          |
| `src/pdf.ts`                    | Складання PDF (pdf-lib), режими A4 / розмір фото |
| `src/store.ts`                  | Черга фото і налаштування чату в Netlify Blobs   |
| `src/telegram.ts`               | Клієнт Telegram Bot API на fetch                 |
| `scripts/set-webhook.mjs`       | Прив'язка бота до задеплоєного сайту             |
| `public/index.html`             | Проста сторінка-заглушка сайту                   |

## Обмеження serverless

Це не той самий бот, що крутиться процесом 24/7, тому є нюанси:

- **Немає автоскладання по таймеру.** Функція живе лише під час обробки одного
  апдейта, тож PDF збирається по кнопці або `/done`, а не «через 3 секунди
  тиші».
- **Ліміт часу функції** (10 с на безкоштовному плані). Тому `MAX_PHOTOS` за
  замовчуванням 20: дуже великі пачки можуть не встигнути завантажитись і
  склеїтись.
- **Фото лежать у Blobs** до складання PDF або `/cancel` — на відміну від
  версії з polling, де вони жили тільки в пам'яті процесу. Після відправки
  файлу черга чату видаляється.
- **EXIF-поворот не застосовується** до зображень, надісланих файлом: Telegram
  стискає звичайні фото вже «рівними», а от оригінальний файл з телефону може
  лягти в PDF повернутим.

Попередня версія бота на Python + aiogram (long polling, автоскладання по
таймеру) лежить в історії гілки — commit `68a4634`.
