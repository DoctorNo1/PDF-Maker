# PDF Maker — телеграм-бот «фото → PDF»

Кидаєш боту фотографії — отримуєш один PDF-файл, де кожне фото окрема сторінка.

## Як користуватись

1. Надсилаєш фото: альбомом або по одному.
2. Бот чекає кілька секунд після останнього фото і сам збирає PDF
   (або одразу по команді `/done`).
3. У відповідь прилітає готовий `photos_YYYYmmdd_HHMMSS.pdf`.

Порядок сторінок = порядок, у якому надіслані фото.

### Команди

| Команда   | Що робить                                              |
|-----------|--------------------------------------------------------|
| `/start`, `/help` | Коротка довідка                                |
| `/done`   | Скласти PDF негайно, не чекаючи таймера                |
| `/cancel` | Викинути накидані фото і почати спочатку               |
| `/mode`   | Перемикає сторінки: A4 (за замовчуванням) ↔ розмір фото |

Приймаються і звичайні фото, і зображення, надіслані файлом (без стиснення) —
другий варіант дає кращу якість.

## Запуск

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env      # і вставити токен від @BotFather
python -m bot.main
```

### Налаштування (`.env`)

| Змінна             | За замовчуванням | Опис                                              |
|--------------------|------------------|---------------------------------------------------|
| `BOT_TOKEN`        | —                | Токен бота від [@BotFather](https://t.me/BotFather) |
| `AUTO_BUILD_DELAY` | `3`              | Скільки секунд тиші чекати перед складанням PDF    |
| `MAX_PHOTOS`       | `100`            | Ліміт фотографій на один PDF                       |

## Тести

```bash
pip install -r requirements-dev.txt
pytest
```

## Як влаштовано

| Файл               | Призначення                                             |
|--------------------|---------------------------------------------------------|
| `bot/main.py`      | Точка входу, polling, меню команд                       |
| `bot/handlers.py`  | Обробники повідомлень, таймер автоскладання             |
| `bot/pdf.py`       | Складання PDF (EXIF-поворот, прозорість, режими сторінок) |
| `bot/storage.py`   | Буфер фотографій у пам'яті, окремий на кожен чат        |
| `bot/config.py`    | Читання `.env` / змінних оточення                       |

Фотографії тримаються в пам'яті процесу до моменту складання PDF і на диск не
пишуться; після відправки файлу буфер чату очищається.
